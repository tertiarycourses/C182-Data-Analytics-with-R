## About the course

A hands-on, instructor-led course for analysts, researchers and managers who work with data. Each topic pairs a short, visual concept briefing with a self-contained R lab and an Excel evidence workbook, so every result you produce is reproducible, reconciled and defensible.

## Learning outcomes

- LO1: Prepare and transform data for analysis using R.
- LO2: Summarise data with descriptive statistics, figures, graphs and tables.
- LO3: Perform quantitative data analysis and interpret the findings.
- LO4: Perform qualitative data analysis and determine significance or effect.
- LO5: Create effective data visualisations in R and interpret research findings.

## Topics covered

1. **Data Preparation and Transformation** — research-data workflow, import/export, tidy structure, cleaning, joins, reshaping and reconciliation
2. **Data Summary** — data types, centre, spread, distributions, grouped summaries and basic plots
3. **Quantitative Data Analysis** — correlation, regression, hypothesis testing, effect size and ANOVA
4. **Qualitative Data Analysis** — text preparation, tokenisation, stop words, term frequency and word clouds
5. **Data Visualization** — grammar of graphics, scales, facets, accessibility, visual QA and communicating findings
